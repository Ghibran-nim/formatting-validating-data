# Formatting & Validating Data

## Project Overview

This project is part of a Data Analyst bootcamp assignment focused on data formatting and data validation using Google Sheets.

The dataset used in this project is the **Superstore dataset**, which contains transaction and sales-related data.

## Objective

The objective of this project is to improve the consistency, readability, and quality of the Superstore dataset through data formatting, duplicate checking, and data validation.

## Tools

* Google Sheets

## Data Formatting

The following formatting tasks were performed on the dataset:

1. Changed the **Discount** column format to percentage.
2. Changed the **Sales** and **Profit** column formats to US Dollar currency ($), with a maximum of two decimal places.
3. Highlighted negative values in the **Profit** column in red.
4. Converted the data from **Ship Mode** through **Region** to **Proper Case**.

## Data Validation

Data validation was applied to the **Segment** column to ensure that only the following values can be entered:

* Corporate
* Consumer
* Home Office

## Duplicate Check

The dataset was checked to determine whether there were any duplicate transactions.

## Result

The Superstore dataset was formatted and validated according to the specified requirements.

The process improved the consistency and readability of the dataset while ensuring that the **Segment** column follows the defined data validation rules.

## Project Files

* `raw_data.xlsx` — Original Superstore dataset before formatting and validation.
* `cleaned_data.xlsx` — Superstore dataset after formatting, validation, and data checking.
